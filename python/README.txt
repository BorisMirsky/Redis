Как пользоваться



- Завести виртуальное окружение. 
  'cd Redis\python\my_env\Scripts'
  'activate'

- Запустить сервер Fast API
  'cd Redis\python\src'
  'uvicorn producer:app --reload'              # 'producer' - в зависимости от запускаемого файла

- В качестве редактора использовал idle, инструкция (запуск из под виртуального окружения) ниже для него:
- Завести в. окружение (см выше)
- 'python -m idlelib.idle'
