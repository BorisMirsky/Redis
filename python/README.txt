Как пользоваться



- Завести виртуальное окружение. 
  'cd Redis\python\my_env\Scripts'
  'activate'

- Запустить сервер Fast API                   #  нужен не во всех примерах
  'cd Redis\python\src'
  'uvicorn producer:app --reload'              # 'producer' - в зависимости от запускаемого файла

- В качестве редактора использован idle. Инструкция запуска из под виртуального окружения:
  Завести вирутальное окружение (см выше)
  'python -m idlelib.idle'
